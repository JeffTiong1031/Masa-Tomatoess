Pad top bar — version 1

Open and Save up in the title bar

Open and Save sit together next to minimise, maximise and close. They are a pair, so they live in the same place. The lower row stays purely about text looks.

What the little dot means. The red dot on the "Untitled" tab means that note is not saved in your files yet. Tabs with no dot are saved files.

The grey words on the right tell you where the note lives, and change to "Not saved yet" for a new note. That is how you know without pressing anything.

Pad top bar — version 2

Save as a word button next to Select

What you first asked for. Only the folder button goes in the title bar; Save is a proper word button at the end of the lower row, and it turns solid when there is something to save.

Start typing…

When the note is already a saved file and everything is written down, the Save button goes quiet — thin outline and the words "Saved" — so the coloured one always means "you have something to save".

Ctrl+S works in both versions. On a new note it opens the save box. On a saved file it just writes it down and flashes "Saved".

The save box

Name plus a folder dropdown

This is what pops up when you save a new note, from the Save button or from Ctrl+S. The dropdown lists your folders, with "New folder…" at the bottom so you never have to leave.

The yes / no boxes

Three questions the app will ask

Small floating boxes in the middle of the screen, with the rest dimmed behind. No more grey browser pop-ups.

Save before closing?

"Untitled" is not in your files yet. If you don't save it, it's gone.

Move to bin?

"Chicken rice" goes to the bin. You can bring it back later.

Delete "Recipes" and everything in it?

4 notes and 2 folders inside go to the bin too.
