# Notes Pad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a personal notepad that opens from any screen, slides up on a phone, floats as a solid window on a computer, and saves as you type.

**Architecture:** All pad rules, merge rules, shortcut rules, and window maths live as pure functions in `src/lib/` so Vitest can pin them. IndexedDB (Dexie) is the device copy; Supabase `notes` is the cloud copy; `mergeNotes` keeps the newer `updatedAt`. A small Zustand store holds only “is the pad open / minimised / where is the window”. `NotesHost` mounts once in `AppShell` so the pad survives navigation. The menu row is a button, not a link.

**Tech Stack:** Next.js 16.2 App Router, React 19.2, TypeScript strict, Tailwind v4, Zustand persist, Dexie, Supabase, Vitest, lucide-react.

**Spec:** [docs/superpowers/specs/2026-09-09-notes-design.md](../specs/2026-09-09-notes-design.md)

## Global Constraints

- **Never hardcode a colour.** Components reference `--mt-*` semantic tokens only. Raw `--mac-*` hues stay inside `globals.css`. Notes does **not** add an eleventh-plus accent.
- **Do not write comments.** Names and structure carry the meaning.
- **No defensive programming.** No guards for states the types exclude.
- **No `instanceof`, no `typeof` branching** to discriminate shapes.
- **Handle exceptions only where there is something to do about them.** Dexie and Supabase catch; pure functions in `notePad.ts` / `noteMerge.ts` / `noteShortcut.ts` / `noteWindow.ts` do not.
- Server Components by default; `'use client'` only on the leaf that needs it.
- Touch targets at least 44px (`min-h-11 min-w-11`).
- `min-h-dvh`, never `h-screen`.
- **Commits are Jeff's alone.** Never add a `Co-Authored-By` trailer or any generated-with attribution.
- Next.js 16 differs from training data. Read `node_modules/next/dist/docs/` before writing App Router code. This feature adds **no new route**.
- Do **not** add Notes to `ALL_LINKS` in `navLinks.ts`. A test must keep asserting that list has no `/notes`.
- Computer window: **no** grey veil and **no** glass. Phone sheet may use the existing `Modal` `sheet` backdrop so tapping the dimmed area closes it.
- Cloud writes need `docs/superpowers/specs/2026-09-09-notes-setup.sql` run in Supabase. Tasks 1–7 work offline against Dexie; Task 8’s live sync check needs the table.
- Branch: cut `feat/notes-pad` from current `main` before the first commit of Task 1.
- Pause after typing before save: `NOTE_SAVE_PAUSE_MS = 400`.

```ts
import type { UserName } from './identity';
import {
  DEFAULT_NOTE_TITLE,
  titleOrDefault,
  type Note,
} from './note';

export { titleOrDefault };

export function nextSortOrder(notes: Note[]): number {
  if (notes.length === 0) return 100;
  return Math.max(...notes.map((note) => note.sortOrder)) + 100;
}

export function seedPad(owner: UserName, nowIso: string, id: string): Note[] {
  return [
    {
      id,
      owner,
      title: DEFAULT_NOTE_TITLE,
      body: '',
      sortOrder: 100,
      createdAt: nowIso,
      updatedAt: nowIso,
    },
  ];
}

export function addNote(
  notes: Note[],
  owner: UserName,
  nowIso: string,
  id: string,
): Note[] {
  return [
    ...notes,
    {
      id,
      owner,
      title: DEFAULT_NOTE_TITLE,
      body: '',
      sortOrder: nextSortOrder(notes),
      createdAt: nowIso,
      updatedAt: nowIso,
    },
  ];
}

export function renameNote(
  notes: Note[],
  id: string,
  rawTitle: string,
  nowIso: string,
): Note[] {
  return notes.map((note) =>
    note.id === id
      ? { ...note, title: titleOrDefault(rawTitle), updatedAt: nowIso }
      : note,
  );
}

export function removeNote(
  notes: Note[],
  id: string,
  owner: UserName,
  nowIso: string,
  replacementId: string,
): Note[] {
  const left = notes.filter((note) => note.id !== id);
  if (left.length > 0) return left;
  return seedPad(owner, nowIso, replacementId);
}
```

```ts
import type { Note } from './note';

export function mergeNotes(
  local: Note[],
  remote: Note[],
  pendingDeleteIds: string[],
): Note[] {
  const pending = new Set(pendingDeleteIds);
  const byId = new Map<string, Note>();
  for (const row of local) {
    if (pending.has(row.id)) continue;
    byId.set(row.id, row);
  }
  for (const row of remote) {
    if (pending.has(row.id)) continue;
    const existing = byId.get(row.id);
    if (!existing || row.updatedAt > existing.updatedAt) {
      byId.set(row.id, row);
    }
  }
  return [...byId.values()].sort((a, b) => a.sortOrder - b.sortOrder);
}
```

```ts
export interface NoteWindowBox {
  x: number;
  y: number;
  width: number;
  height: number;
}

export const NOTE_WINDOW_MIN_WIDTH = 280;
export const NOTE_WINDOW_MIN_HEIGHT = 220;
export const NOTE_WINDOW_DEFAULT_WIDTH = 360;
export const NOTE_WINDOW_DEFAULT_HEIGHT = 420;

export function defaultNoteWindow(viewW: number, viewH: number): NoteWindowBox {
  return clampNoteWindow(
    {
      x: viewW - NOTE_WINDOW_DEFAULT_WIDTH - 24,
      y: 72,
      width: NOTE_WINDOW_DEFAULT_WIDTH,
      height: NOTE_WINDOW_DEFAULT_HEIGHT,
    },
    viewW,
    viewH,
  );
}

export function clampNoteWindow(
  box: NoteWindowBox,
  viewW: number,
  viewH: number,
): NoteWindowBox {
  const width = Math.min(viewW, Math.max(NOTE_WINDOW_MIN_WIDTH, box.width));
  const height = Math.min(viewH, Math.max(NOTE_WINDOW_MIN_HEIGHT, box.height));
  const x = Math.min(Math.max(0, box.x), Math.max(0, viewW - width));
  const y = Math.min(Math.max(0, box.y), Math.max(0, viewH - height));
  return { x, y, width, height };
}
```

- Create: `src/lib/noteSync.test.ts`

**Interfaces:**
- Consumes: `loadNotes`, `saveNote`, `deleteNoteLocally`, `loadPendingDeletes`, `clearPendingDelete`; `fetchNotes`, `upsertNote`, `deleteNoteRemote`; `mergeNotes`; `seedPad`.
- Produces: `reconcileNotes(owner: UserName, nowIso: string, newId: string): Promise<Note[]>`

`reconcileNotes` algorithm (keep this exact order):

1. `local = await loadNotes(owner)`
2. `pending = await loadPendingDeletes(owner)`
3. `remoteFetch = await fetchNotes(owner)`
4. If `remoteFetch.status === 'ok'`, `merged = mergeNotes(local, remoteFetch.rows, pending)`; else `merged = mergeNotes(local, [], pending)`
5. If `merged.length === 0`, `merged = seedPad(owner, nowIso, newId)`
6. For each id in `pending`, `deleteNoteRemote`; on `true`, `clearPendingDelete`
7. For each row in `merged`, `saveNote` (device now matches merge)
8. If `remoteFetch.status === 'ok'`, `upsertNote` each merged row (ignore individual `false`; device already has them)
9. Return `merged`
