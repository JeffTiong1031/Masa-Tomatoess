# Finance Implementation Plan

> Steps use checkbox (`- [ ]`) syntax for tracking. Each pure module is built test-first: write the failing test, watch it fail, write the code, watch it pass.

**Goal:** Replace the `/finance` preview with a working personal expense tracker: per-person categories, entries, quick templates and a weekly or monthly budget, with an automatic Saving entry when each budget period closes.

**Architecture:** Every rule — money formatting, budget periods, the bar, Week/Month switching, Saving creation and recalculation, month navigation, daily and summary totals, the swipe threshold — is a pure function in `src/lib/finance*.ts` with a Vitest file beside it. `src/lib/financeRepo.ts` is the only file that talks to Supabase. `FinanceBoard.tsx` is the one stateful client component; it loads everything for the signed-in person, runs settlement, and hands plain values to presentational children. `Entry` is a union on `source` (`'hand' | 'saving'`), so a Saving entry's `periodStart` and `budgetSen` exist by type.

**Tech Stack:** Next.js 16.2 App Router, React 19.2, TypeScript strict, Tailwind v4, Supabase, Vitest, lucide-react. No new dependencies.

**Spec:** [docs/superpowers/specs/2026-10-02-finance-design.md](../specs/2026-10-02-finance-design.md)

## Global Constraints

- Colours through `--mt-*` tokens only; raw `--mac-*` stay in `globals.css`.
- No comments. No defensive guards. No `instanceof` / `typeof` shape checks.
- Catch only in the repo, where the network really fails.
- Server Component page; `'use client'` on the board and its interactive leaves.
- Touch targets ≥ 44px. `min-h-dvh`, never `h-screen`.
- Today is `malaysiaDate()`; rollover uses `msUntilNextMalaysiaMidnight()`.
- Money is integer sen end to end; only `financeMoney.ts` formats it.
- Text on the bar card stays `--mt-text`; only the bar carries tone colour.
- Commits as Jeff, no attribution trailers.
- Only touch: `src/app/(life)/finance/`, `src/components/finance/`, new `src/lib/finance*`, `globals.css` (new tokens), `docs/superpowers/`.
- `/finance` needs `docs/superpowers/specs/2026-10-02-finance-setup.sql` run before it shows data; until then it shows the setup message.
